# Ui-DayniteballClone

A front-end clone of the Daynite Cricket Tennis Ball website built for UI practice. Multi-page layout built with plain HTML, CSS, and JavaScript — no frameworks.

---

## Project Structure

```
UI-DAYNITEBALLCLONE/
│
├── daynite.html          # Home page
├── daynitestyle.css      # Home page styles
├── about.html            # About Us page
├── about.css
├── about.js              # Counter animation for stats
├── blog.html             # Blog page
├── blog.css
├── contactus.html        # Contact page with form and map
├── contactus.css
├── sponsorship.html      # Sponsorship form page
├── sponsorship.css
├── daynite.js            # Shared JS (hamburger menu toggle)
├── Media/                # Images and assets
└── README.md
```

---

## Pages

- **Home** — Hero slider, about section, products, gallery
- **About** — Company info, mission, vision, team, animated stats counter
- **Blog** — Two cricket blog posts
- **Contact Us** — Address, Google Maps embed, contact form
- **Sponsorship** — Sponsorship inquiry form

---

## Built With

- **HTML** — Page structure
- **CSS** — Styling, flexbox layout, responsive navbar
- **JavaScript** — Hamburger menu toggle, animated stats counter on About page
- **Canva** — Logo and favicon design
- **Google Maps Embed** — Location on Contact page
